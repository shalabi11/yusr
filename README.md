# yusr_app

`yusr_app` is a Flutter application that helps users manage daily Islamic routines in one place. It brings together prayer times, Quran browsing, adhkar, reminders, and other helpful tools in a clean mobile experience.

## English

### Project Description
Yusr App is designed to support everyday worship and productivity.

### Key Features
- Prayer times and countdowns
- Quran reading and navigation tools
- Adhkar and daily content
- Reminders and assistant features
- N8N workflow automation for the Yusr assistant (`Yusr Assistant Basic Chain`)
- Cross-platform support with Flutter
